API Keys

Programmatic access

Use API keys to create payment sessions from your own backend without logging in. Add the key as an x-api-key header.

# Create a payment session
curl -X POST https://your-settl.com/api/pay/charge \
  -H "x-api-key: sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{"amount": 25.00, "message": "Order #1234"}'

# Response includes:
{ "checkout_url": "...", "reference": "...", "url": "solana:..." }

# Poll for confirmation (no auth needed)
curl https://your-settl.com/api/pay/status/:reference
